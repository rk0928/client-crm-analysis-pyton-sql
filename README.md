# Client CRM Analysis

## Project Overview

This project analyzes a client relationship management (CRM) dataset using Python, Excel, and SQL.

The goal of this project was to:

- Clean and prepare client data
- Import the dataset into MySQL
- Analyze active and dormant clients
- Evaluate client growth trends over time
- Identify recent client acquisition activity
- Calculate dormant client percentages

## Tools Used

- Python (Pandas)
- Jupyter Notebook
- MySQL Workbench
- Excel
- GitHub

## Dataset

The dataset contains:

- Client ID
- Bra Size
- Last Contact Date
- Date Added
- Active/Dormant Status

Total Records: 325

## SQL Analysis

Key questions answered:

1. Active vs Dormant Clients
2. Clients Added by Year
3. Most Recent Client Additions
4. Dormant Client Percentage
5. Client Growth Percentage by Year

## Key Findings

- Total Clients: 325
- Active Clients: 226
- Dormant Clients: 99
- Dormant Rate: 30.46%
- 63.08% of all clients were added in 2026
- Client growth accelerated significantly in 2024–2026
